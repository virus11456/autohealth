1. 上傳 Apple Health 匯出檔

📱 偵測到你正在用 iPhone / iPad
Apple Health 的 export.zip 解壓後常常超過 500MB，iOS Safari 記憶體限制較嚴格（約 250-500MB），大檔可能上傳到一半被系統重載 （表現：點上傳後閃一下回到這個頁面）。

建議做法：
  1. 把 匯出.zip 存到 iCloud 雲碟 / Google Drive
  2. 用桌機 Safari / Chrome 開這個網頁，從雲端下載後再上傳
⚠ 偵測到剛才上傳被中斷
可能是檔案太大、瀏覽器記憶體不足把分頁重載。建議用桌機重試。
📂 拖曳 匯出.zip 或 export.xml 到這裡
或點此選擇檔案。所有處理都在本地，不會上傳。
📦 上傳失敗 / 沒電腦怎麼辦？
方法 1：用桌機 / 筆電上傳（最穩）
  1. iPhone「健康」→ 個人頭像 → 匯出所有健康資料 → 取得 匯出.zip
  2. 把 匯出.zip 存到 iCloud 雲碟 / Google Drive / Dropbox
  3. 用桌機打開這個網頁、登入雲端、下載到電腦、上傳
方法 2：AirDrop 到 Mac
  1. iPhone 匯出時直接 AirDrop 給 Mac
  2. Mac Safari / Chrome 打開這個網頁，上傳 匯出.zip
方法 3：本機跑 Streamlit 版（會 Python 的話）
  1. git clone https://github.com/virus11456/autohealth
  2. pip install -r requirements.txt && streamlit run app.py
  3. 瀏覽器開 localhost:8501，左側上傳。Python 解析沒有 iOS Safari 的記憶體限制
方法 4：先看示範資料
點上面綠色按鈕，會載入合成資料讓你先看儀表板長什麼樣。確認有用再想辦法上傳真實資料。
取得方式：iPhone「健康 App → 個人頭像 → 匯出所有健康資料」會產生 匯出.zip。
🧪 示範模式　·　目前看的是合成資料，不是你自己的健康紀錄。
